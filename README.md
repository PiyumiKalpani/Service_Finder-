# Service Finder Web Application

## 📌 Project Overview
The Service Finder Web Application is a front-end based system developed using HTML, CSS, and JavaScript. This platform allows users to either register as service providers or hire workers based on their needs. It simplifies the process of finding, booking, and managing services in a user-friendly way.

## 🚀 Features
- User Registration and Login System
- Option to register as:
  - Service Provider
  - Service Seeker (Customer)
- Browse different service categories
- Book appointments with service providers
- View and manage bookings
- Delete or cancel appointments
- Interactive and responsive user interface

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript

## 🎯 Purpose of the Project
This project was developed to demonstrate front-end web development skills and simulate a real-world service marketplace platform. It focuses on improving user experience in searching and booking services efficiently.

## ⚙️ How to Run the Project
1. Download or clone the repository  
2. Open the project folder  
3. Run `service.html` in any web browser
